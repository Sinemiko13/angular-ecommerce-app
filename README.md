# Angular E-Commerce Application

Bu proje, Angular kullanılarak geliştirilmiş temel bir e-ticaret web uygulamasıdır.

## Özellikler
- Kullanıcı giriş sistemi (authentication)
- Route koruma (CanActivate)
- Ürün listeleme
- Sepet işlemleri
- Component tabanlı yapı

## Teknolojiler
- Angular
- TypeScript
- REST API
